Since our main focus is the LDL and HDL size changes in each diet groups over time, we’ll plot those changes.

Even though the Average LDL size is smaller for the PLM diet group, the decrease in LDL size from Visit 1 to Visit 9 is almost the same for both groups. There are a lot of overalapping in the errorbars indicating that there is likely not a significant difference in the two diet groups. However, we still need to test these differences using linear mixed models.

We can see that the PLM diet group has larger HDL size, but the decrease in average HDL size from visit 1 to visit 9 is visibly more in the LMP group than the PLM. Again, there are strong overlapping error bars.

What does it mean for the model to be the same?

The model is the same when you can get the same means from the model parameters and the relationship between predictor and response are the same for each model (units of predictors do not affect the models).
